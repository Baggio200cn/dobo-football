## 这个项目在做什么

不是"预测彩票中奖"，而是**验证一件事**：用公开数据训练的模型，能不能、以及在多大程度上接近博彩市场的判断水平——并把这个过程完整记录下来。

核心指标是**概率质量**（Brier score）而非"猜中几场"。

### 已公开的记录

| 类别 | 内容 |
|---|---|
| **12 轮模型迭代** | 3 次有效 / 8 次无效 / 1 次数据不可用 —— 失败全部保留 |
| **最大单次收益** | v6「把模型改简单」（Brier −0.0297，占全部收益 86%）|
| **第 26101 期** | 赛前预测期望 7.82 场，实际命中 **8 场**（偏差 +0.18）|
| **关键发现** | 连伤停数据都加不出增量 —— 公开信息市场早已定价 |

## 数据与方法

- **数据源**：[football-data.co.uk](https://www.football-data.co.uk/)（公开免费）
- **规模**：106,835 场 · 36 个联赛 · 992 支球队
- **模型**：Elo 评分 + 泊松强度回归 + Dixon-Coles 修正 + LightGBM 融合
- **验证**：**时间序列切分**（严禁随机划分，防未来信息泄漏）
- **跨联赛校准**：UEFA 国家系数（欧战场次用）

### 三条方法论纪律

1. **预测必须赛前锁定并留时间戳** —— 事后补的预测没有意义
2. **评价标准事先定死** —— 期望命中数、概率区间都在开奖前写好
3. **失败照实记录** —— 只报成功的曲线不可信

## 目录结构

```
engine/          模型与流程代码
  ├─ data.py         数据下载与清洗（36 联赛）
  ├─ model.py        Elo / 泊松 / Dixon-Coles
  ├─ features.py     特征工程（含赔率轨迹）
  ├─ timecv.py       时间序列交叉验证
  ├─ sfc.py          胜负彩预测
  ├─ euro.py         欧战预测（UEFA 系数校准）
  ├─ sfc_lock.py     期次锁定（带时间戳）
  ├─ sfc_review.py   赛后复盘
  ├─ make_cover.py   文章封面生成
  └─ batches/        预测存档（不可事后修改）
articles/        复盘文章（.md）+ 封面
site/            网站（Vercel 部署）
.github/workflows/  定时自动化
```

## 本地运行

```bash
pip install -r requirements.txt
cd engine
python run.py           # 更新数据 → 回测 → 出预测
python sfc.py           # 胜负彩预测
python sfc_lock.py      # 锁定本期（赛前）
python sfc_review.py 26101 03003133010300   # 赛后复盘
python make_cover.py    # 生成文章封面
python build_articles.py # 构建文章清单
```

## 自动化

| 任务 | 时间（北京时间） | 动作 |
|---|---|---|
| 出预测 | 周五 20:00 | 更新数据 → 预测 → 锁定 → 提交 |
| 复盘 | 周一 10:00 | 抓开奖 → 复盘 → 更新台账 → 提交 |

提交后 Vercel 自动重新部署网站。
